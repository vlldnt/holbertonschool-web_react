## 📝 Project Description

Deep dive into **React Redux performance optimization**. Learn how to identify and fix unnecessary re-renders, use memoized selectors with Reselect, and understand the difference between `useState` and `useRef` for optimal component behavior.

### 🎯 Learning Objectives

- Understand React performance issues and unnecessary re-renders
- Use memoized Redux selectors to optimize state derivation
- Differentiate between `useState` and `useRef` and when to use each
- Identify and prevent unnecessary component re-renders
- Write performant, optimized React-Redux applications

---

## 🔧 Key Concepts

- **Re-renders** - Understanding when and why React re-renders components
- **Memoized Selectors** - Using Reselect to cache derived state and avoid recomputation
- **useState vs useRef** - Choosing the right hook for the right use case
- **Performance Profiling** - Identifying bottlenecks in React applications
